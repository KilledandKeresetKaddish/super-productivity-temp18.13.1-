## 一、项目架构(已定型,勿推翻)

- **载体**:SP 官方插件(zip:manifest.json + plugin.js + icon.svg,扁平结构)。
  plugin.js 在应用主上下文运行,注入 `<style>` + 极少量 JS。用户平台:桌面
  Firefox 网页版 + iOS App。SP ≈ v18(v18.13.1)。
- **设计语言**:tarot-gold-style skill(现 v5.2)。Token 不变:bg #0c0b10 /
  gold #c79a4f / bright #e8cb8c / line #b08d4c / muted #9d8a5e / h1 #f3e3bd /
  danger #d9776b / ok #7fae6f。铁律:1px 发丝金线、禁彩虹霓虹、阴影含金。
- **JS 仅三件事**:注入 CSS、favicon、月视图 style.order 排序(零 DOM 搬动)。

## 二、v1.9 分层策略(核心新约定)

SP 会在触屏设备的 body 上挂 `isTouchOnly` 类。以此为唯一开关,单 zip 通吃:

- **全平台(含 iOS)**:只有零开销静态样式——发丝金线、静态辉光
  (box-shadow)、封印态、字体、配色。
- **仅桌面网页(`body:not(.isTouchOnly)`)**:全部持续动画——h1 金箔流光
  (v1.9 起手机端为静态金箔渐变)、Finish Day 呼吸辉光(tarotGlowBreathe,7s)。
- 性能纪律照抄官方 rainbow 主题源码注释:任务行(热路径)零动画、零逐行
  blur;backdrop-filter 只给大面板;发光全静态。今后加美化必须过这三条。
- 后台资源占用:CSS 动画在窗口最小化/标签页隐藏时浏览器不绘制,CPU≈0;
  窗口可见但未聚焦时会持续合成(桌面才有动画,量级为单元素 box-shadow 插值)。

   已完成(isDone)封印态:透明度 .55 + 虚线金线。全静态。
   注:任务聚焦时的 :focus 边框走 SP 原生规则,取色 --palette-primary-400
   (#cfaa58,我方 palette 覆写内的金),视觉自洽,勿再覆盖。
4. **新增 10) Finish Day**:静态柔光全平台;桌面加 7s 呼吸
   (含 prefers-reduced-motion 豁免)。
5. **新增 11) 手机底栏**:顶部发丝金线;中央 + 按钮三层静态金辉
   (选择器 `.mobile-bottom-nav .add-task-button`)。
6. **新增 12) iOS 键盘修复(方案 A)**:
   - 根因(源码实证):add-task-bar 的 bottom =
     `calc(var(--keyboard-height) + var(--s2))`,而 `--keyboard-height` 直接取
     Capacitor `keyboardWillShow` 上报值(global-theme.service.ts:624-637),
     **无任何钳制**;讯飞等第三方输入法虚报高度 → 输入条被顶到屏幕顶部。
   - 修复:`bottom: min(原公式, 45dvh) !important`(45vh 兜底行在前)。
     苹果原生键盘(实际 ≈ 屏幕 40% 以内)不受影响。**微调旋钮:嫌还高就把
     CSS 里两处 45 改小(如 42/40)。**
   - 此为 SP 上游 bug,根治应在 global-theme.service 用 visualViewport 钳制,
     值得报 issue。
7. manifest 1.9.0。JS 未改。

## 五、已调查存档(勿重复调查)

- **月视图拖拽/点空格建任务**:原生零支持(day cell 无处理器、事件条
  cdkDragDisabled、drag-over 样式是死代码)。插件技术上可做(事件条 DOM 带
  `id="t-<taskId>"`、格子带 data-day、PluginAPI updateTask 无字段白名单可改
  dueDay;addTask 支持 dueDay 不支持定时),但工作量 150-250 行且版本脆弱。
  **用户已决定不做。** 上游 issue #6078 经查是"任务起止日期"功能请求,与月视图
  拖拽无关,开放中、无 PR、无维护者回应。
- **底栏第 4 按钮改跳 Schedule**:按钮组硬编码于
  `core-ui/mobile-bottom-nav`(routerLink 写死),设置里不可配。结论:自托管时
  改模板一行即可;插件 DOM 注入属脆弱 hack,不做。
- **SP 原生"用户主题 CSS"通道**:存在(设置里可传,存 IDB),但校验器禁外链
  url()/@import(Google Fonts 进不来)且无 JS,故塔罗主题维持插件路线。
